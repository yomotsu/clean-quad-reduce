# Clean Quad Reduce

四角面の列をまとめて、元の縦・横のエッジの流れを保ちながら頂点を削減するツールです。
Blenderアドオン版とCodexスキル版は、それぞれ必要な削減エンジンを同梱しており、相互にインストールする必要はありません。

対応・検証環境: **Blender 5.1以降（5.1.2で検証）**。削減処理に外部Pythonパッケージ、AI API、ネット接続は不要です。スキル版の操作・評価はCodexが担当します。VRM出力には別途VRM Add-on for Blenderが必要です。

## アドオン版

1. `dist/clean_quad_reduce-1.0.0.zip`を、Blenderの「プリファレンス → エクステンションを入手 → 右上メニュー → ディスクからインストール」でインストールします。
2. オブジェクトモードで対象メッシュを選択し、3Dビューの`N`パネル → **Clean Quad**を開きます。
3. **Analyze / 分析**で構成を確認し、品質と保護設定を選びます。
4. **Create Preview / 削減プレビュー**を実行します。処理中はビューを確認でき、`Esc`で取り消せます。
5. 結果を確認し、**Apply Preview / 適用**または**Revert Preview / 破棄**を選びます。
6. VRMとして出す場合は、アバターに含める全メッシュを選択し、**Export VRM + Count**で実頂点数を確認します。

適用前は元メッシュを変更せず、元オブジェクトを一時的に隠します。適用時は元のオブジェクト名・リグ参照を残してメッシュを差し替え、削減前のメッシュを`CQR_Backups`に保持します。プレビュー後に元メッシュを編集した場合は、その編集を上書きせず再生成を要求します。

詳細な結果はBlenderのテキストエディターに生成される`CQR Reduction.json`で確認できます。アドオンは分析・プレビュー・適用・取り消しにCodexを使いません。

## スキル版

`dist/blender-clean-quad-reduce-1.0.0.zip`を展開し、`blender-clean-quad-reduce`フォルダーを`~/.codex/skills/`に配置します。Codexを再読み込みした後、次のように依頼できます。

> $blender-clean-quad-reduce このモデルを、斜め格子を作らず四角面の流れを保って削減して。テクスチャと表情を保護し、元データを残してVRMの実頂点数も調べて。

スキルは同梱の`reduce_mesh.py`と`clean_quad_core.py`で動きます。Clean Quad Reduceアドオンの登録やインストールは不要です。実行中のBlenderへPython接続する方法のほか、Blenderを背景起動して保存済みファイルを処理する方法も使えます。

```sh
"/Applications/Blender.app/Contents/MacOS/Blender" \
  --background /path/to/input.blend --python-exit-code 1 \
  --python /path/to/blender-clean-quad-reduce/scripts/reduce_mesh.py \
  -- --job /path/to/job.json
```

ジョブ例（実際のオブジェクト名と出力先に変更してください）:

```json
{
  "action": "reduce",
  "objects": ["Body", "Clothes"],
  "preset": "BALANCED",
  "settings": {
    "max_error": 0.01,
    "preserve_uv": true,
    "grid_strategy": "LOOPS_ONLY"
  },
  "apply": true,
  "output_blend": "/path/to/output.blend",
  "output_vrm": "/path/to/output.vrm",
  "report": "/path/to/report.json",
  "vertex_limit": 10000
}
```

`output_vrm`は省略できます。背景起動したBlenderでVRMエクスポーターが有効である必要があります。既存出力は既定では上書きしません。`apply:false`なら、現在のシーンに可逆なプレビューを作ります。詳しい操作・評価手順は同梱の`SKILL.md`に記載しています。

## 斜め格子を作らない仕組み

既定の **Aligned reference / 良好版と同じ方式** は、別ワークツリーで良好だった処理を移植したものです。接触部の誤差予算を半分にし、削減係数を0.9→2.0→3.0と段階的に上げ、形状差が大きい箇所を保護して再処理します。球状関節は構造を検出できた場合だけ緯線・経線を間引き、極を三角面の扇形にします。元の材質と参照面から投影した法線を使います。

この方式ではUn-Subdivideを一切使いません。四角面の並びと、極・列の終端に必要な三角面を区別して扱います。球状の構造を検出できないオブジェクトは、通常の列削減に進みます。テクスチャ・表情キー・頂点カラー・保護グループがある場合、またはUV境界保護を有効にした場合は、保護を優先するStrict処理に自動で切り替え、レポートに記録します。

- 三角面を適切なペアで四角面へ戻した後、その四角面の縦・横の経路を記録します。
- 列をまとめてできる新しい辺が、その元の経路をまっすぐ辿る場合に限って採用します。セルを斜めに横切る辺は採用しません。
- 奇数回のUn-Subdivideは格子を45度回転させるため使用しません。偶数回でも方向検査を通過したものだけを採用します。
- Strict方式は適用前に全ての結果の辺を再検査します。Aligned方式は元の列の統合と検出した球の緯線・経線から面を作り、極・列の終端に三角面を認めます。どちらもレポートの`edge_flow_preserved`で確認できます。

元のモデルがすでに斜め格子を持っている場合は、その流れ自体を自動で縦横に作り直す機能ではありません。三角化済みモデルから作者の元の四角面を完全に復元できるとは限らないため、初期の四角面復元もワイヤーで確認してください。

## 品質設定

| 設定 | 意味 |
|---|---|
| Aligned reference | 良好だった版と同じ接触部保護・段階的な列削減・球状関節処理・形状誤差の再補正 |
| Detail | 形状優先。UV境界を保護し、列の結合だけで削減 |
| Balanced | UV・形状を保護する標準設定 |
| Minimal | 許容形状差を広げて削減。初期状態ではUV境界保護がOFF |
| Max sampled error | 元と結果の表面を双方向にサンプリングして確認する最大形状差 |
| Part error ratio | 小さい部品を潰さないため、部位寸法に応じて削減を制限する比率 |
| Quad fraction | 四角面率の下限。入力がそれ以下なら入力以上を維持 |
| Max aspect / Min angle | 結合してできる四角面の縦横比と角度の制限 |
| Protect group | その頂点グループに非ゼロのウェイトを持つ頂点を保護 |
| Protect UV boundaries | UVの切れ目と、削除する頂点のUV補間誤差を確認 |
| Grid | 自動的な規則格子の統合、または四角面の列だけの削減 |
| VRM limit | 出力結果の比較基準。ここに近づいた時点で削減を止める設定ではない |

Aligned方式は極に三角面を使うため、四角面率だけで流れの良し悪しを判定しません。四角面率下限やウェイト補間誤差の制限はStrict方式で使い、Aligned方式では元の頂点のウェイトと規則的な列を残します。一般利用では再現用の`aligned_target_vertices`は`0`のままにし、品質条件まで削減してください。

距離は**ワールド空間のBlender単位**です。メートル基準のモデルなら`0.005`は5 mmです。全体スケールに合う値で指定してください。

テクスチャのあるモデルは`Protect UV boundaries`を有効にし、通常は`Quad strips only`を選びます。表情シェイプキーが動かす頂点とその周囲は保護し、残る頂点に全てのキーを対応付けて検証します。表情がモデルの広い範囲に及ぶ場合は、削減できる量が小さくなります。

分離頂点の接続は、逆向きで一致する境界辺・一致するウェイト・表情座標を持つものに限定します。曖昧な重なりや孤立した接触点は接続しません。接触リムや指先など、確実に残したい箇所には保護グループを指定してください。

削減は**品質条件を満たす操作がなくなるまで**進めます。最大編集回数に達した場合はレポートで区別します。指定した頂点数まで必ず減らせる機能ではなく、方向・形状・UVを守るために削減量が小さくなるモデルもあります。

## 確認すること

形状差はサンプリングによる検証で、厳密な最大距離の数学的証明ではありません。元の法線は可能な範囲で引き継ぎますが、陰影・テクスチャ・シルエット・関節を曲げた状態は目視でも確認してください。アーマチュア以外のモディファイアは残し、形状差はベースメッシュを対象に測定します。

VRMは三角面として書き出されます。編集用の四角面は`.blend`に残します。UV・法線の分離で頂点が増えるため、Blenderの頂点数とVRMの頂点数は別に報告します。VRM計測はファイル内のPOSITIONアクセサを読み、空の出力を成功扱いにしません。

## 開発・配布

このリポジトリは、アドオンとスキルを一緒に管理する独立したリポジトリです。Rigodotify本体のチェックアウトは不要です。`addon/`、`skill/`、`tests/`、`reference/`をGitで管理し、生成物の`dist/`と検証出力は管理対象から除きます。モデルファイルは同梱しません。

クローン直後は、リポジトリのルートで次を実行して配布ZIPを作成してください。Python 3の標準ライブラリだけでビルドできます。

```sh
python3 build.py
```

`addon/clean_quad_reduce/core.py`と`aligned.py`が開発時の削減エンジンの原本です。`python3 build.py`でスキルへ同じコードを同梱し、独立した2つのZIPを`dist/`に作成します。インストール後は相互参照せず、それぞれのコピーだけで動作します。

```sh
blender --background --factory-startup --python-exit-code 1 --python tests/blender_checks.py
blender --command extension validate dist/clean_quad_reduce-1.0.0.zip
```

追加の検証方法と外部の基準モデルの条件は[`tests/README.md`](tests/README.md)を参照してください。
