# Reference recipe provenance

`upstream/`は、別ワークツリーで良好だったAlignedモデルを作成した際のスクリプトの保存コピーです。元は実行中のBlenderの状態と`/tmp/`に依存しており、このフォルダーを配布版の実行入口として使いません。

汎用化した実装は`../addon/clean_quad_reduce/aligned.py`、共通の保護・検証・入出力は`../addon/clean_quad_reduce/core.py`です。どちらもスキルへ独立コピーを同梱します。

最終の実行順序は、交差部6 mmと周囲1リングの誤差予算を半分にする → 削減係数0.9、2.0、3.0の順で列をまとめる → 元表面から7 mmを超えた点と左右反転点の周囲12 mmでは予算を0.35倍にして元メッシュから同じ段階処理をやり直す、です。球状関節は緯線・経線を検出して間引き、極を三角面にします。最後に元の材質、UV、参照面から投影したカスタム法線を保持します。これらの距離は基準モデルのワールド単位で、汎用ツールでは設定可能です。

`../tests/aligned_reference_check.py`で、完成モデル内に残した元メッシュから再生成し、頂点位置・面の接続・向き・VRMの頂点数と三角面数を照合します。基準モデルのトポロジーを配布ZIPへ埋め込んで再生する方式ではありません。
